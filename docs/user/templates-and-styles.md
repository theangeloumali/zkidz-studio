# Templates and styles

For anyone starting a new edit. A template sets how footage comes in and the first prompt; a style sets the look. Last reviewed
2026-10-24.

## Templates (Home screen)

| Template                  | Ingest     | What the starter prompt asks for                                                  |
| ------------------------- | ---------- | --------------------------------------------------------------------------------- |
| Talking-head short        | `single`   | A 60-second short: trim pauses and retakes, English captions, masked swears, hook |
| Vlog                      | `join`     | A 45-second vlog from your clips in order, speech kept, light SFX, captions       |
| Screen-recording showcase | `showcase` | The screen recording as a panel over your face cam, synced to when you mention it |

`join` joins several clips in the order you dropped them. `showcase` places a screen recording over the camera. The prompt is a
starting point; edit it before sending.

## Styles (setup)

| Style   | Cards                 | Sound     | Brand intro |
| ------- | --------------------- | --------- | ----------- |
| `zkidz` | core, accent          | light     | yes         |
| `plain` | none                  | none      | no          |
| `loud`  | core, accent, special | every cut | yes         |

Captions and cut-based effects are on in every style. Each style card plays a 5-second sample. Change the style later from Setup.
The presets live in `themes/zkidz/presets/`.
