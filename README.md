# ZKidz Studio

An open-source, local-first AI video editor. Drop in your footage, type a prompt, and watch Claude cut, caption and animate your
short-form video live. It runs on your own machine with your own Claude access.

**Status: planning (pre-alpha).** No runnable app yet.
