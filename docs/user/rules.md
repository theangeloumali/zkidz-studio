# Rules

For anyone who wants the agent to follow the same instructions every time. Last reviewed 2026-10-24.

A rule is a standing instruction, such as "Never blur my own face" or "Keep captions under two lines". Open **Rules** in the top
navigation, type the rule (500 characters at most) and add it.

- Rules apply to every project, from the next agent session, not the one already running.
- Turn a rule off with its switch, or delete it.
- Only you create rules. Nothing the agent says becomes a rule unless you add it here.
- Rules go to the agent in a marked block alongside your style's guidance.
